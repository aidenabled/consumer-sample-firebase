# Contributing

Use Node.js 22 and Java 21. Run `npm ci`, `npm run lint`, `npm test`, and `npm run test:integration` before opening a pull request. Keep examples small and reusable. Describe the resulting behavior and include the checks you ran.

Do not commit environment files, service account keys, credentials, production data, or customer-specific assets. Use placeholder configuration in sample files. Report suspected credential exposure privately to the repository maintainers instead of posting the values in a public issue.

Contributions are provided under this project's MIT license.
